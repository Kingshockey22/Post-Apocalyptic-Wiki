POST APOCALYPTIC WIKI
Version 2.9 - Through Session 11
=======================================

A player-facing encyclopedia for the Post Apocalyptic D&D campaign.
Live site: https://kingshockey22.github.io/Post-Apocalyptic-Wiki/

CONTENTS
--------
index.html   The entire wiki in a single self-contained file
README.txt   This file

PUBLISHING (GitHub Pages)
-------------------------
1. Open the Post-Apocalyptic-Wiki repository on GitHub.
2. Choose Add file > Upload files.
3. Drag in index.html and README.txt, replacing the existing copies.
4. Commit the changes. The live site updates within a minute or two.

No build step or other files are needed.
